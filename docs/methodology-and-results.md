# Methodology and Results Plan

## GEO Criteria

The demo scores pages on a 100-point scale using the following on-page signals:

- `15` points: title quality and length
- `15` points: meta description quality and length
- `10` points: single H1 usage
- `10` points: heading hierarchy and section depth
- `15` points: body content depth
- `10` points: readability
- `20` points: keyword placement and density
- `9` points: contextual links

## Experimental Workflow

1. Choose several webpages from different industries such as ecommerce, software, and local services.
2. Capture the original page source or text and analyze it with the tool.
3. Record the original GEO score, readability, keyword density, and heading/link counts.
4. Apply the generated optimized version.
5. Re-run the optimized content through the analyzer.
6. Compare the before-and-after metrics.

## Presentation Talking Points

- The parser converts raw webpage input into structured elements used by search and answer systems.
- The scoring engine makes GEO evaluation measurable and repeatable.
- The optimizer demonstrates how rule-based content changes can raise discoverability metrics.
- The comparison view makes the impact legible for non-technical audiences.

## Limitations

- This is a classroom prototype, not a production SEO platform.
- The scoring system is heuristic and should be interpreted as a decision aid.
- Real GEO performance would need validation with live traffic, click-through behavior, and ranking changes.
